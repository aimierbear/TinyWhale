# Folder: /hooks/lib/fractal-agent

1. **地位**：现有全局分形系统的跨 Agent 公共后端；不是独立项目，也不是新的规则真源。
2. **边界**：只接收版本化中立 action 和 manifest；vendor 原始 payload 必须在 `adapters/` 内归一化。
3. **约束**：默认只在显式 state/install 根下写入；安装与配置操作默认 dry-run；不得记录原始 session、规则正文、工具输入或凭据。

## 依赖图谱
- **上游**：Claude、Codex、Kimi、Grok、Pi、Cursor 的薄适配器或手动 Skill/MCP。
- **下游**：现有 `.folder.md` / 根 README、私有依赖图谱索引、`fractal-self-description` 和本地 SQLite 状态。

## 成员清单
- `bin/`：稳定机器入口。
- `activation/`：六端 owner-scoped 全局激活声明。
- `bridges/`：必须由宿主原生加载的薄桥接模板；当前包含 Pi Extension。
- `fractal_agent/`：合同、路径、状态、动作、审计、体检和发布实现。
- `graph_scanner/`：随核心 release 哈希闭合的图谱扫描器及运行依赖。
- `contracts/`：action、manifest、审计输出的封闭 JSON 合同。
- `manifests/`：六端能力与证据声明。
- `fixtures/`：仅 synthetic/allowlisted 的离线事件证据。
- `tests/`：unit、integration、eval、characterization 和 performance 门禁。
